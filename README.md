# Featherweight

Vertical-scroll webcomic site. Static HTML, hosted on GitHub Pages.

## Publishing a chapter

1. Export your strips into `source/chNN/`, named so they sort in reading order
   (`01.png`, `02.png`, ...). Any heights are fine — they get stitched into one
   continuous strip before slicing, so the joins never show.
2. Run:

       ./tools/publish.sh ch02 --title "Your chapter title"

3. Open `comic/ch02/notes.html` and write your end-of-chapter notes.
   Optional — leave it and the section just doesn't appear.
   **This file is created once and never overwritten by a rebuild.**
4. Re-run step 2 to push the notes live.

Bonus drawings: drop `.webp` files into `comic/chNN/extras/` and re-run.

## Useful flags

    --quality 92      higher quality, bigger files (default 88)
    --status draft    build it, but hide it from the site
    --date 2026-09-14 override the publication date
    --regen           rebuild pages only, no re-slicing

## What's generated vs. hand-edited

Generated by the script — don't hand-edit, your changes get overwritten:
`index.html`, `chapters.html`, `read/*/index.html`, `comic/*/chapter.json`,
`comic/chapters.json`

Yours to edit freely:
`about.html`, `comic/*/notes.html`, `assets/css/site.css`

## Your originals

`source/` is gitignored — the full-size art never goes to GitHub. Those files
are the masters and exist only on your machine, so keep a backup of them
somewhere else.
